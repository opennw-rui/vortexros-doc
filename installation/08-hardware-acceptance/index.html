真机验收

项目

通过条件

离线安装

从实体 U 盘启动，离线完成验签和安装。拔盘后能从目标盘登录。

控制台

从实际需要的串口或本地显示进入安装器与已安装系统。

存储与固件

识别目标盘和所需控制器，能从目标盘独立引导。

网络驱动与 DPDK

核对 PCI、驱动、IOMMU 组与 Active Mode。接管和撤销后验证实际流量。

CPU、内存与队列

核对在线 CPU、SMT、NUMA、大页、队列和实际绑定。

业务与恢复

从隔离对端验证静态与动态路由、双向转发、管理登录和重启后恢复。

升级和回退

用签名包从已知版本试启动、确认后回退，并复核配置和业务。

用 display interface brief 和 display dataplane interfaces topological 记录接口和归属。保留镜像版本、校验值、端口连接、对端和通过条件，便于重现实测结果。
